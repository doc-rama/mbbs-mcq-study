# MBBS MCQ Study — Chapter-Centric V3

Built from the supplied 12,004-question workbook.

### Chapter-centric features
- Subject → chapter navigation
- Each chapter independently tracks:
  - Progress (% of unique questions attempted)
  - Accuracy
  - Unanswered
  - Wrong
  - Saved/bookmarked
  - Current consecutive study-day streak
- Chapter-specific analytics dashboard
- Chapter-wise mock history and mock accuracy
- Recent question activity per chapter
- Mock builder supports multiple subjects + multiple chapters
- Mock history records the chapters included in each mock
- No duplicate questions within a mock

Deploy as a static site to Vercel/Netlify. No build command is required.
Updated for Vercel deployment.
